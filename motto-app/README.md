# motto! 試用版（GitHub Pages + Firebase 無料枠）

## 構成
| 役割 | 使うもの | 料金 |
|---|---|---|
| 画面の公開 | GitHub Pages | 無料 |
| ログイン | Firebase Authentication（匿名ログイン＋招待コード） | 無料 |
| データ保存 | Cloud Firestore | 無料枠（1日 読み取り5万・書き込み2万回まで） |
| AI | Firebase AI Logic（Gemini Developer API の無料枠） | 無料（課金アカウントを紐付けない限り請求されません） |

ファイル：`index.html`（画面）／`app.js`（動き）／`config.js`（設定）／`firestore.rules`（データの保護ルール）

---

## セットアップ手順（30分ほど）

### 1. Firebaseプロジェクトを作る
1. https://console.firebase.google.com で「プロジェクトを作成」（名前例：motto-pilot）。Googleアナリティクスはオフで可。
2. プランは **Spark（無料）のまま**にする。**課金アカウントは紐付けない**（紐付けなければ請求は発生しません）。

### 2. Webアプリを登録して設定値を貼る
1. プロジェクトの概要 →「ウェブ」アイコン（`</>`）→ アプリ名を入れて登録（Hostingのチェックは不要）。
2. 表示された `firebaseConfig` の中身を、`config.js` の `firebaseConfig` に貼り付ける。

### 3. 匿名ログインを有効にする
「Authentication」→「始める」→「ログイン方法」→「匿名」を有効にして保存。

### 4. Firestoreを作ってルールを設定する
1. 「Firestore Database」→「データベースを作成」→ 場所は `asia-northeast1（東京）`、「本番環境モード」で作成。
2. 「ルール」タブを開き、`firestore.rules` の中身を全部貼り付けて「公開」。

### 5. 招待コードを登録する
「Firestore Database」→「データ」→「コレクションを開始」
- コレクションID：`secrets`
- ドキュメントID：`invite`
- フィールド：`code`（string）＝ 好きな招待コード（例：`motto2026`）

※このコードを知っている人だけが参加できます。参加者にだけ伝えてください。

### 6. AI（Gemini）を有効にする
1. 「AI Logic」（構築 → AI Logic）→「始める」→ **Gemini Developer API** を選ぶ（課金不要の方）。
2. 案内に沿って有効化する。
3. 使えるモデル名を確認し、`config.js` の `AI_MODEL` と合っているか確認する（使えない場合は、表示されている無料のFlash系モデル名に書きかえる）。

### 7. GitHub Pagesで公開する
1. GitHubで新しいリポジトリを作る（例：`motto-pilot`、Public）。
2. このフォルダの全ファイル（`.nojekyll` を含む）をアップロードする。
3. リポジトリの「Settings」→「Pages」→ Source：`Deploy from a branch`、Branch：`main` / `/(root)` で保存。
4. 数分後に `https://ユーザー名.github.io/motto-pilot/` で開けるようになる。

### 8. 公開URLをFirebaseに許可する
「Authentication」→「設定」→「承認済みドメイン」→「ドメインを追加」で `ユーザー名.github.io` を追加。

### 9. 自分を運営者にする
1. 公開URLを開き、招待コードとニックネームを入れて参加する。
2. 「マイページ」の下に表示される **ユーザーID** をコピー。
3. Firestore の「データ」で、コレクション `admins`、ドキュメントID＝コピーしたユーザーID、フィールド `role`（string）＝`admin` を作成。
4. ページを開き直すと、マイページに「運営用」パネルが出る。ここで試用期間を設定する。

これで準備完了です。参加者には **公開URL と 招待コード** を伝えてください。

## 運営メモ
- **通報**：運営用パネルに一覧で表示されます。投稿の削除もそこから行えます。
- **利用状況**：参加者数・投稿数・相談の利用率などを運営用パネルで確認できます。データはFirestoreの「データ」からも見られます。
- **試用終了後**：運営用パネルで終了日を過ぎれば自動で投稿停止。完全に閉じる場合は、`secrets/invite` のコードを変更するか、GitHub Pagesを停止します。
- **端末を変えた場合**：匿名ログインのため、別の端末やブラウザでは別の参加者として扱われます（同じ招待コードで再参加は可能）。

## 注意（必ずお読みください）
- **18歳以上のみ**：Gemini APIの規約で、18歳未満が利用する（可能性がある）アプリでの利用が禁止されています。高校生を参加させる場合は、AI部分を別のサービスに切り替える必要があります。
- **AIへの入力データ**：Gemini APIの無料枠では、入力内容がGoogleのサービス改善に使われる場合があります。画面にも注意書きを入れていますが、参加者にも事前に伝えてください。
- **AIの使いすぎ対策**：1人1日30回まで（`config.js` の `AI_DAILY_LIMIT`）。無料枠の上限に達するとAIは止まり、用意した質問・例に自動で切り替わります。より厳密に守りたい場合は Firebase App Check（reCAPTCHA）の設定がおすすめです。
- **APIキーの制限（推奨）**：Google Cloud コンソール →「APIとサービス」→「認証情報」で、ブラウザキーの「ウェブサイトの制限」に `https://ユーザー名.github.io/*` を追加すると、他サイトからの悪用を防げます。
- **鍵ありBEHIND**：鍵の判定は画面側で行っています。技術的に詳しい人であれば中身を読むことができるため、本当に秘密にしたい内容は書かないよう案内してください。
